「最終版」「最終版2」「最終版_本当に最後」。ファイル名で時系列を追おうとして、迷子になったことはありませんか。

名前の頭に日付がついていれば、並べ替えるだけで新しい順・古い順に並びます。ただ、数十個のファイルに1つずつ手でつけるのは面倒です。

この記事では、PowerShellでファイル名の頭に更新日を一括でつける方法を紹介します。先に予定を表で確認でき、改名したあとも記録から元の名前に戻せます。

## 結論：「2026-03-09_report.pdf」の形に、まとめて変えられる

名前の頭につけるのは、ファイルの更新日です。「年-月-日_」の形にするので、名前順に並べると日付順になります。

動き方は次のとおりです。

- 最初は「予定の表示」だけで、ファイルは1つも変わらない
- 実行すると、改名の記録（改名ログ.csv）が残る
- すでに「2026-01-05_」のような日付で始まる名前は、そのまま残す
- 同じ名前がすでにあるときは、改名せずにスキップする

日付の形を「年-月-日」にしているのは、数字の桁がそろっていて、名前順がそのまま日付順になるからです。

## 手順1：整理したいフォルダを決める

まず、日付をつけたいフォルダを決めます。次の手順では、そのフォルダの場所を1行目に書きます。

試すときは、実際に使っているフォルダではなくコピーを入れたテスト用のフォルダから始めると安心です。

## 手順2：スクリプトを貼り付ける（まずは予定の表示）

PowerShell を開き、次のコードを貼り付けて Enter を押します。1行目の `$src` は手順1で決めたフォルダの場所に書き換えてください。

```powershell
$src   = "$env:USERPROFILE\Documents\テスト"   # 対象フォルダ
$apply = $false                                  # $false=予定を見るだけ / $true=実際に改名
$log   = Join-Path $src '改名ログ.csv'

function Invoke-Rename($apply) {
  $files = Get-ChildItem -LiteralPath $src -File | Where-Object { $_.Name -ne '改名ログ.csv' }
  foreach ($f in $files) {
    if ($f.Name -match '^\d{4}-\d{2}-\d{2}_') { continue }
    $new  = '{0:yyyy-MM-dd}_{1}' -f $f.LastWriteTime, $f.Name
    $dest = Join-Path $src $new
    if (Test-Path -LiteralPath $dest) {
      [pscustomobject]@{ 結果='スキップ'; 元=$f.Name; 先=$new }; continue
    }
    if ($apply) {
      try {
        Rename-Item -LiteralPath $f.FullName -NewName $new -ErrorAction Stop
        [pscustomobject]@{ 結果='改名'; 元=$f.Name; 先=$new }
      } catch {
        [pscustomobject]@{ 結果='失敗'; 元=$f.Name; 先=$new }
      }
    } else {
      [pscustomobject]@{ 結果='予定'; 元=$f.Name; 先=$new }
    }
  }
}

$rows = Invoke-Rename $apply
$rows | Format-Table 結果, 元, 先 -AutoSize
if ($apply) { $rows | Where-Object 結果 -eq '改名' | Export-Csv $log -Encoding UTF8 -NoTypeInformation }
```

実行すると、次のような表が出ます。

```
結果 元         先
---- --         --
予定 memo.txt   2026-11-02_memo.txt
予定 photo.jpg  2026-05-20_photo.jpg
予定 report.pdf 2026-03-09_report.pdf
```

「予定」の行がこれから変える名前です。この段階では、ファイルは1つも変わっていません。

## 手順3：表の見方

見るのは「先」の列です。頭につく日付が思っていた日と合っているかを確かめます。

注意したいのは、日付の元になるのが**更新日**だという点です。ファイルを開いて保存し直すと更新日は変わります。ダウンロードしたファイルや、他の場所からコピーしたファイルでは、更新日がコピーした日になっていることもあります。

「作成日」ではなく更新日を使っているので、「いつ作ったか」を残したいファイルには向きません。

## 手順4：問題なければ、実際に改名する

表に納得できたら、2行目の `$apply = $false` を `$apply = $true` に書き換えて、もう一度実行します。

今度はファイル名が変わります。変わった内容は同じフォルダの「改名ログ.csv」に1行ずつ残ります。

## うまくいかないとき

つまずきやすい点を2つ挙げます。

**1. 赤い文字のエラーが出て、何も変わらない**

`$src` の場所が間違っていることが多いです。エクスプローラーでフォルダを開き、上のアドレスバーをコピーして貼り付けると確実です。コードの一部だけが貼り付けられていないかも見てください。

**2. 表に「失敗」と出て、一部が変わらない**

そのファイルを別のアプリが開いている状態であることが多いです。アプリを閉じてからもう一度実行します。失敗した行は改名ログに入らないので、元に戻すときの邪魔になりません。

## 間違えたとき：改名ログから元に戻す

「やっぱり戻したい」ときは、次のコードを実行します。1行目は手順2と同じフォルダの場所に書き換えます。

```powershell
$src = "$env:USERPROFILE\Documents\テスト"
Import-Csv (Join-Path $src '改名ログ.csv') -Encoding UTF8 |
  ForEach-Object { Rename-Item -LiteralPath (Join-Path $src $_.先) -NewName $_.元 }
```

改名ログには、「元の名前」と「変えた後の名前」が1行ずつ書かれています。それを逆向きにたどって、全部を元の名前に戻します。

ただし、改名したあとにさらに名前を変えたファイルは、戻せません。また、改名ログは実行のたびに上書きされるので、戻すなら次の改名より前にやってください。

## 向いている人・向いていない人

向いているのは、次のような人です。

- 資料や写真のファイルを、時系列で並べたい
- ファイル名の頭に日付をつけるルールにしたいが、手作業は続かない
- 先に結果を見てから、実行するか決めたい

向いていないのは、次のような人です。

- 「作成日」や、撮影日・ファイルの中に書かれた日付を使いたい人
- ファイルの中身で名前を決めたい人（このスクリプトは中身を読みません）
- 他の人と共有しているフォルダの名前を変えたい人（相手のリンクが切れることがあります）

特に共有フォルダは名前を変えると、他の人が貼っていたリンクや、別のファイルからの参照が切れることがあります。自分だけが使うフォルダで使ってください。

## 動かして確かめたこと

この記事の手順はWindows 11 の Windows PowerShell 5.1 で動かして確かめました（2026年11月23日）。

使ったのは、自分の実際のフォルダではなく作ったばかりのテスト用フォルダです。更新日をわざと変えたダミーのファイルを4つ置き、次の動きを見ました。

- 予定の表示のあいだは、ファイル名が変わらないこと
- 更新日が頭につく形で改名されること
- すでに日付で始まるファイルは、そのまま残ること
- 改名ログから、元の名前に戻せること

確かめていないこともあります。

- PowerShell 7 や、Mac・Linux での動作
- 何千個ものファイルがあるフォルダでの速さ
- OneDrive で同期しているフォルダでの動作
- 日本語以外の名前や、とても長い名前のファイル

最初は少数のファイルで試すことをおすすめします。

## 明日やること

明日は手順2だけ実行してみてください。

予定の表を眺めるだけで、自分のフォルダに、どの日付のファイルがどれだけあるかが分かります。改名するかどうかはそれを見てから決めれば十分です。
