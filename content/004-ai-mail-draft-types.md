返信メールの1行目で、手が止まったことはありませんか。

断りたいけれど角が立たない言い方が浮かばない。確認したいことはあるのに、失礼にならない聞き方が分からない。そんなとき、AIに下書きを頼むと、最初の一文が出るだけでも気持ちがラクになります。

この記事では、メールの返信をAIに下書きしてもらうときの、3つの型を紹介します。個人情報を入れずに頼む方法と、送る前に必ず確認する点も書きます。

## 結論：返信の目的に合わせて、「承諾」「お断り」「確認」の3つの型を使い分ける

返信メールの目的は、ほとんどが次の3つに分けられます。

- 承諾：依頼や提案を受ける
- お断り：依頼や提案を断る
- 確認：分からない点を相手に聞く

目的を先に決めてAIに伝えると、狙いに近い下書きが返りやすくなります。「返信を書いて」とだけ頼むより、目的と条件を書いた方が、直す手間が減ります。

## 手順1：先に、入力していい情報かを決める

メールを貼る前に、中身を確認します。AIの入力欄に貼った内容の扱いは、サービスや契約、設定によって違います。

使う前に、次の2つを確認してください。

- 勤務先に、AIサービスの利用ルールがあるか
- 使うサービスが入力した内容をどう扱うと説明しているか（公式のページで確認します）

禁止されているなら使いません。迷ったときは、上司か情報管理の担当者に聞いてください。

## 手順2：相手の情報は、貼らずに「状況の説明」にする

相手のメールを丸ごと貼る必要はありません。次のように、状況だけを自分の言葉で書けば足ります。

- 相手の名前や会社名は書かず、「取引先の担当者」「社内の先輩」と書く
- 金額や日付は、必要なときだけ書き、書くなら「来週の水曜」のようにぼかす
- 電話番号、メールアドレス、住所、署名は貼らない

下書きに相手の名前を入れたいときは、返ってきた文章の「〇〇様」の部分を、自分で書き換えます。

## 手順3：3つの型をコピペで使う

どの型も`【　】` の中を自分の状況に置き換えます。

**承諾の型**

```
取引先の担当者から、【依頼の内容】の依頼を受けました。
受ける方向で返信メールの下書きを書いてください。

【条件】
- 丁寧だが、かたすぎない文面
- 作業の完了予定は【来週の水曜】と伝える
- 3〜5文の短さ
- 宛名と署名は空欄のままにする
```

**お断りの型**

```
社内の先輩から、【依頼の内容】の依頼を受けました。
今回は難しいので、お断りする返信メールの下書きを書いてください。

【条件】
- 断る理由は【手が空かない】とだけ書き、詳しく言い訳をしない
- 感謝の言葉を1文入れる
- 代わりにできることがあれば、【別の日なら対応できる】と添える
- 3〜5文の短さ
- 宛名と署名は空欄のままにする
```

**確認の型**

```
取引先の担当者から、【案件の名前】の連絡が来ました。
次の点が分からないので、確認する返信メールの下書きを書いてください。

【分からない点】
- （1つ目）
- （2つ目）

【条件】
- 質問は箇条書きにして、答えやすくする
- 返事がほしい時期は【今週中】と書く
- 宛名と署名は空欄のままにする
```

3つの型に共通するのは、「宛名と署名は空欄のまま」と頼んでいる点です。これで、個人情報をAIに渡さずに済みます。

## 手順4：送る前に、必ず自分で確認する

AIの文章はそのまま送らないでください。次の5点を見ます。

1. 事実が合っているか（日付、金額、数量、約束の内容）
2. 相手との関係に合った言葉づかいか（敬語の上げすぎ、下げすぎ）
3. 自分が言っていないことを、約束していないか
4. 宛名と署名が、自分で正しく書き込まれているか
5. 添付ファイルの言及があるなら、実際に添付したか

特に3つ目が大事です。AIは親切のつもりで「喜んでお引き受けします」「すぐに対応します」のように、自分が決めていない約束を足すことがあります。

## うまくいかないとき

よくあるつまずきを2つ挙げます。

**1. 文面が長すぎる**

条件に「3〜5文」と書いても長くなることがあります。そのときは「半分の長さにしてください」と頼み直します。

**2. かたすぎる、またはくだけすぎる**

「相手は初めてやり取りする取引先です」「相手は同じチームの後輩です」と、関係を一言足すと、言葉づかいが合いやすくなります。

## 向いている人・向いていない人

向いているのは、次のような人です。

- 返信の最初の一文が出てこなくて、時間がかかる
- お断りや確認のような、言いにくい文面が苦手
- 送る前に自分で読んで直す時間は取れる

向いていないのは、次のような人です。

- 内容がすべて機密で、状況を言い換えられない人
- 謝罪や、クレーム対応のように、気持ちを込めるべき文面を任せたい人
- 読み直さず、AIの文章をそのまま送りたい人

謝罪やお悔やみのような場面は、定型の文面では気持ちが伝わりにくいことがあります。自分の言葉で書いてください。

## 動かして確かめたこと

この記事の依頼文はAIサービスの画面に入力して、返答を確かめたものではありません。

そのため、「このAIで、必ずこう返る」とは言えません。AIの返答は使うサービスや時期によって変わります。

この記事で整理したのは、依頼文の組み立て方です。目的、条件、空欄にする部分を分けて書く型は、AIへの頼み方として一般的なものです。ただし、特定のサービスで期待どおりに返るかは、確かめていません。

試すときは、実在の相手や案件が分からないダミーの状況で、一度動きを見てから、本番の返信に使ってください。

## 明日やること

明日は手元の返信待ちのメールを1通選んでください。

そのメールが「承諾」「お断り」「確認」のどれにあたるかを決めるだけで十分です。目的を言葉にできると、返信の最初の一文は書きやすくなります。
